# 📚 StudyMate - Student Study Planner

StudyMate is a simple and user-friendly web application
that helps students organize their daily study activities.

## ✨ Features

- Add study tasks
- Add subjects and deadlines
- Mark tasks as completed
- Delete tasks
- Track study progress
- Save tasks using LocalStorage
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the StudyMate folder.
3. Open index.html in your browser.

## 🎯 Project Purpose

This project was created as my first web development
project to practice HTML, CSS and JavaScript.
